# kaizen-exercise-media

A pinned personal copy of the media the Kaizen app uses, so upstream changes cannot break it:

- Exercise GIFs, WebP stills and JSON (1,323 exercises, `<muscle>/<slug>.gif|.thumb.webp`, `api/`) copied from
  https://github.com/JahelCuadrado/ExerciseGymGifsDB (branch `main`, July 2026).
- `yoga/` - yoga pose line drawings used by the Kaizen app.
